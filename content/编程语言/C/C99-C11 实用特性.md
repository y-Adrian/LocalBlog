# C99/C11 实用特性

内核（C89/C11 方言）、现代 **gcc/clang** 用户态和 **DPDK** 代码里，C99/C11 特性能 **少写 bug、少写宏**。本篇只收 **日常真会用** 的条目，不追求标准全书。

---

## 1. 读完能带走什么

- 会用 **指定初始化** 写驱动表、协议常量。  
- 理解 **柔性数组成员（FAM）** 与一次分配。  
- 用 **`_Generic`** 做类型安全的轻量宏替代。

---

## 2. 指定初始化（designated initializer）

```c
struct config {
    int port;
    int timeout_ms;
    const char *name;
};

struct config cfg = {
    .port = 8080,
    .name = "edge",
    /* .timeout_ms 未写 → 零初始化 */
};
```

| 优点 | 场景 |
|------|------|
| 顺序无关 | 大型 `struct`、缺省字段多 |
| 可读 | 设备树式静态表、ops 结构 |

**C++20** 有类似 designated init，但规则不同；混用时见 [[C 与 C++ 混用]]。

数组同样支持：

```c
int a[5] = { [2] = 9, [4] = 1 };
```

## 3. 复合字面量（compound literal）

```c
struct point { int x, y; };

void foo(void) {
    struct point *p = &(struct point){ .x = 1, .y = 2 };
    /* p 指向复合字面量，生命周期到包含它的块结束 */
}
```

适合 **临时传参**；不要返回指向它的指针（悬空）。

## 4. 柔性数组成员 FAM

```c
struct packet {
    uint32_t len;
    uint8_t  data[];   /* C99 FAM：不占 sizeof，尾部变长 */
};

struct packet *p = malloc(sizeof *p + payload_len);
p->len = payload_len;
memcpy(p->data, src, payload_len);
```

```mermaid
flowchart LR
  HDR[固定头 sizeof packet] --> PAY[变长 data]
  PAY --> ONE[malloc 一次]
```

| 对比 | FAM | 指针 + 二次分配 |
|------|-----|-----------------|
| 分配次数 | 1 | 2 |
| cache | 连续 | 可能分散 |

内核 `sk_buff` 等结构有类似思想；用户态协议 buffer 常用。

**注意**：仅 **最后一个成员** 可为 FAM；C11 也支持 `[0]` 旧写法（语义同 FAM）。

## 5. `_Generic`（C11）

编译期按 **表达式类型** 选函数，替代部分宏：

```c
#include <stdio.h>

#define print(x) _Generic((x), \
    int:     print_int,     \
    double:  print_double,  \
    default: print_other     \
)(x)

void print_int(int v)    { printf("int %d\n", v); }
void print_double(double v) { printf("double %f\n", v); }
void print_other(void *p)   { printf("other %p\n", p); }
```

| 用途 | 说明 |
|------|------|
| 类型安全 `min`/`max` | 避免宏重复求值 |
| 轻量泛型 log | 嵌入式无 C++ 模板时 |

## 6. 其他常用 C99/C11

| 特性 | 示例 | 说明 |
|------|------|------|
| **`//` 注释** |  ubiquitous |  |
| **变长数组 VLA** | `int a[n];` | 栈上；**大 n 危险**；内核禁用 |
| **`stdint.h`** | `uint32_t` | 协议必选 |
| **`bool`** | `<stdbool.h>` |  |
| **`restrict`** | 见 [[C 内存模型与未定义行为]] | 优化提示 |
| **`_Static_assert`** | `static_assert(sizeof(int)==4, "...");` | 编译期断言 |
| **`_Alignas`** | 对齐控制 | C11；或编译器 `__attribute__((aligned))` |
| **`_Atomic`** | C11 原子 | 简单计数；复杂用 pthread |

## 7. 与编译标准旗标

```bash
gcc -std=c11 -pedantic -Wall -Wextra foo.c
```

| 项目 | 建议 |
|------|------|
| 内核模块 | 跟内核 **Makefile** 的 `ccflags-y` |
| DPDK | 通常 gnu11 |
| 嵌入式 | 在 `-std=c11` 与编译器扩展间写进文档 |
