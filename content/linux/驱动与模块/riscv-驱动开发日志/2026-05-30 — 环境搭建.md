## 1.4 现象与日志

### 1.4.1 安装 docker 成功，但是 docker 使用时出现问题

I use the wrong command `brew install docker` so I met this:
```shel
~> docker images
failed to connect to the docker API at unix:///Users/debris/.docker/run/docker.sock; check if the path is correct and if the daemon is running: dial unix /Users/debris/.docker/run/docker.sock: connect: no such file or directory
```
With command `brew install docker` you just installed the **Docker CLI**, you didn't install the **Docker Engine(daemon)** and **Linux virtual environment**.

You can solve this problem with many ways, here we recommend **Docker Desktop**:
```shell
# you can remove the docker you installed before with this
brew uninstall docker

# then run this command
brew install --cask docker
```

### 1.4.5 usb-ttl

```shell
ls /dev/tty*

# you may see
/dev/tty.usbserial-11420
```

尝试连接串口：
```shell
screen /dev/tty.usbserial-11420 115200
```
No output.

That’s outrageous — the RX/TX labels on the purchased serial adapter are reversed.

Once the wiring was correct, the serial port started showing output.
 
```
picocom -b 115200 /dev/cu.usbserial-11420
# You should install picocom first, you can alse use screen or  other tools
```

### 1.4.7 compile buildroot

Not recommend. It too difficult on Mac. if you want to create your ko, you just build the kernel.

```shell
docker run --privileged --platform linux/amd64 -it -v "$(pwd)":/home/work milkvtech/milkv-duo:latest /bin/bash

# 只编内核 build_kernel
cd /home/work
build_kernel
```
环境变量初始化脚本：
```shel
source /home/work/build/envsetup_milkv.sh milkv-duos-musl-riscv64-sd
export CC=${CROSS_COMPILE}gcc
export CXX=${CROSS_COMPILE}g++
export AR=${CROSS_COMPILE}ar
export LD=${CROSS_COMPILE}ld
echo "环境初始化完成，CC=$CC"
```
