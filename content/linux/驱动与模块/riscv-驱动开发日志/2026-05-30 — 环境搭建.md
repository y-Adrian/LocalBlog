## 1.4 现象与日志

### 1.4.1 安装 docker 成功，但是 docker 使用时出现问题

I use the wrong command `brew install docker` so I met this:
```shel
~> docker images
failed to connect to the docker API at unix:///Users/debris/.docker/run/docker.sock; check if the path is correct and if the daemon is running: dial unix /Users/debris/.docker/run/docker.sock: connect: no such file or directory
```
With command `brew install docker` you just installed the **Docker CLI**, you didn't install the **Docker Engine(daemon)** and **Linux virtual environment**.

You can solve this problem with many ways, here we recommend **Docker Desktop**:
```shell
# you can remove the docker you installed before with this
brew uninstall docker

# then run this command
brew install --cask docker
```

### 1.4.7 compile buildroot

```shell
# 启动 docker
docker run -it --rm \
  --network=host \
  -v $(pwd):/root/milkv \
  -v $(pwd)/dl:/root/milkv/dl \
  -v $(pwd)/ccache:/root/milkv/ccache \
  -w /root/milkv/duo-buildroot-sdk-v2 \
  milkvtech/milkv-duo:latest /bin/bash

# 开启缓存加速
export BR2_DL_DIR=/root/milkv/dl
export CCACHE_DIR=/root/milkv/ccache
export USE_CCACHE=1

cd /root/milkv/duo-buildroot-sdk/buildroot-2021.05
make O=/root/milkv/output menuconfig
make O=/root/milkv/output -j$(nproc)
cd ../
./build.sh milkv-duos-sd


docker run -it --rm \
  --privileged -itd \
  --network=host \
  -v $(pwd):/root/work \
  -v $(pwd)/dl:/root/work/dl \
  -v $(pwd)/ccache:/root/work/ccache \
  -w /root/work/duo-buildroot-sdk-v2 \
  buildroot /bin/bash
  
  # 自己制作docker
  FROM ubuntu:22.04

ENV DEBIAN_FRONTEND=noninteractive

RUN apt-get update && apt-get install -y \
    build-essential \
    git \
    wget \
    curl \
    rsync \
    file \
    unzip \
    python3 \
    python3-pip \
    cpio \
    bc \
    bison \
    flex \
    libssl-dev \
    libncurses5-dev \
    libncursesw5-dev \
    xz-utils \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /root/work

# 可选：避免权限问题
RUN useradd -m builder
USER builder
```
