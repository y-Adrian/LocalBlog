## 0.1 测试问题：
![[Pasted image 20260603033441.png]]

**问题定位**：fops 没有 `.llseek`，内核使用 `default_llseek` 但它更新的是 `f_pos`，而 `debris_read` 直接用 `*ppos`（即 `f_pos`）——所以 lseek 其实是有效的，真正的问题是 `debris_write` 将 `*ppos` 强制置 0，导致 **write 覆盖了 lseek 设置的值**。

**修复方式**：实际上问题在驱动：fops 没有注册 `.llseek`，内核用 `default_llseek` 但它对自定义设备不可靠。

#### 0.2.5.2 添加测试节点
在根节点 `/ { ... };` 里面加一个无害节点，例如：
```shell
/ {
    model = "...";

    dtb_test {
        compatible = "myvendor,dtb-test";
        status = "okay";
        test-value = <1234>;
        test-string = "hello-dtb";
    };

    // ... existing nodes ...
};
```

如果原文件已经有根节点 `/ { ... };`，就把 `dtb_test` 放进去，不要再重复写一个新的 `/ {}`。

完整示意：
```shell
/dts-v1/;

#include "xxx.dtsi"

/ {
    model = "Milk-V Duo S";
    compatible = "milkv,duos", "sophgo,sg2000";

    dtb_test {
        compatible = "myvendor,dtb-test";
        status = "okay";
        test-value = <1234>;
        test-string = "hello-dtb";
    };
};
```
