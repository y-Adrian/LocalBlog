## 仓库怎么放文件

- **博文**：只写在 `content/`（Obsidian 与 Quartz 共用）。
- **配套代码实验**：`labs/`（本地 `make` 用，编译产物不进 Git）。
- **站点工程**：`quartz/`、`scripts/`；构建输出在 `public/`（已忽略）。

维护者说明见 `docs/仓库目录说明.md`（`draft: true`，不发布到站点）。
