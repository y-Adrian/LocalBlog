# 仓库目录说明

> `draft: true` — 仅供本仓库维护者阅读，**不会** 发布到 GitHub Pages。

## 你会改动的

| 路径 | 用途 |
|------|------|
| **`content/`** | **唯一正式博文目录**（Obsidian 笔记 → Quartz 建站） |
| `labs/` | 博文配套的 C/C++ 小实验源码（不发布） |
| `.cursor/rules/` | Cursor 写作规则 |

## 一般不要手改 / 构建生成

| 路径 | 用途 |
|------|------|
| `quartz/`、`quartz.config.ts` | Quartz 4 站点生成器 |
| `scripts/` | 内容校准、`blog-activity` 等脚本 |
| `public/` | `npx quartz build` 输出（已在 `.gitignore`） |
| `node_modules/` | npm 依赖 |
| `blog-activity.cache.json` | 活动页缓存（可本地生成，已忽略提交） |
| `docs/`（本文件所在） | 上游 Quartz 文档 + 本说明 |

## `content/` 一级分类

| 目录 | 内容 |
|------|------|
| `linux/` | 嵌入式 Linux、内核、驱动、文件系统 |
| `网络与DPDK/` | Socket、DPDK 教程与实践 |
| `编程语言/` | C/C++、Go、Rust |
| `分布式系统/` | 共识算法等 |
| `工程基础/` | Git、CMake、设计模式 |
| `数据库/`、`系统调试/` | 专题 |
| `成长路径/`、`学习疑问/` | 清单与疑问本 |
| `leetcode/` | 刷题记录（可选发布策略） |

## 常见「无关 diff」从哪来

1. **`labs/` 里 `make` 后的二进制、`.dSYM`** — 应被 `.gitignore`；若曾误提交，用 `git rm --cached` 去掉跟踪。  
2. **`public/`、`node_modules/`** — 构建/安装产物，不应进 Git。  
3. **暂存区误删全库** — 若 `git status` 出现几百个 `D`，多为 `git rm --cached` 误操作；用 `git restore --staged .` 后重新 `git add`（勿在未理解前提交）。

## 本地构建

需 **Node ≥ 22**（见 `package.json` engines）。在仓库根目录：

```bash
npm install
npx quartz build
```
